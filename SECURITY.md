# Security

`dsh-sound-cue` is a browser-only plugin. It does not send data anywhere, does not read files, and does not run host-side tools.

- Audio is synthesized locally with the Web Audio API.
- It only reads the session list snapshot already provided by DeepSeek Harness.
- There is no telemetry and no remote sound download.

If you find a problem, open a GitHub issue on this repository.
